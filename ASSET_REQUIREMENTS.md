## Integrating approved films

Edit `public/media/manifest.json`. Null slots produce intentional fallbacks without failed fetches or blocking loaders. Set `hero.src` to an approved same-origin MP4. Set `story.src` and select `strategy: "seek"` for efficient/all-keyframe footage or `"frames"` for single-GOP/expensive reverse seeking. For broad browser support, ship H.264/yuv420p MP4 with fast-start metadata. Keep CORS enabled for cross-origin media; self-hosting is preferred.

The `frames` path uses a module worker for demux/software decode and bounded JPEG snapshots. JPEG storage caps at 64 MB. Bitmap LRU caps at 56 entries **and** 64 MB; at most 8 bitmap decodes are in flight. Frames are downsampled to at most 960px width to respect the decode budget. Unsupported decode falls back to one muted half-speed native pass with requestVideoFrameCallback capture, using the same bounded JPEG/bitmap cache. If that capture API or playback is unavailable, queued native seeking is used. Native seeking requires correct HTTP byte-range support from the media server. Browser fixtures verify mechanisms, not the absent human choreography. Fit and exact crop should be calibrated with final footage.

The final photographic still and the procedural interactive bottle are separate concept representations. Final packaging design and ingredient/formulation claims require approved product specifications.
